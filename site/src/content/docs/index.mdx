Welcome. Changeset Second Opinion helps a volunteer reviewer with a flagged OpenStreetMap edit. It gathers the public evidence for one changeset, asks a small model ten yes or no questions about it, shows every answer, and suggests where the case belongs in your queue. If a reply to the mapper would help, it drafts one for you to edit. You can try it on demo data in a few minutes, with no OpenStreetMap account, no GPU and no AWS account. New here? Read [what it is](./start/what-it-is/), then follow the [quickstart](./start/quickstart/).

## What it will not do

- It **never writes to OpenStreetMap**. It reads public data. The one extra request to OpenStreetMap is the sign-in exchange, with read-only scope.
- **Lanes only order the queue.** Nothing is hidden, nothing closes by itself and nothing is posted by itself.

## How these docs are organised

Every page is one of four kinds, and its first line says who it is for. **Tutorials** teach by doing. **How-to guides** get one task done. **Reference** pages are complete and dry, and the ones for the API, the command line, the settings, the roles and the schemas are generated from the code. **Explanations** say why. The idea comes from [Diátaxis](https://diataxis.fr/).
