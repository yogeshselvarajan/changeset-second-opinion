# Getting help

- **Using the tool:** start with the [docs](site/src/content/docs/index.mdx) (the published site is linked from the README). The FAQ and the sign-in troubleshooting page answer most first questions.
- **A question or an idea:** open an issue with the "Idea" form, or start a discussion if the repository has them turned on.
- **Something is broken:** open an issue with the "Bug report" form. Please leave out secrets, invite codes, session cookies and personal data.
- **A docs page is wrong:** use the "Docs problem" form, or the "Edit page" link at the bottom of the page.
- **A security problem:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).

This is a volunteer project made by one developer. Replies can take a few days.
